# Vol.4 공식 원문 넣는 곳

Vol.4는 공식 원문을 우선한다. 아래 파일을 받은 그대로(이름 그대로) 이 폴더에 넣고 push하면,
클라우드에서 형식을 확인해 `data/manual/vol04_inputs.csv`의 잠정값을 공식값으로 바꾼다.
